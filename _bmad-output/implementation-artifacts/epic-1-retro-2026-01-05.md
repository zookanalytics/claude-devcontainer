## Challenges & Learnings

### Challenge 1: Reference Code Assumptions
**What happened:** Pre-commit hook initially skipped type-check because the reference (lint_example) omitted it for performance reasons on a larger codebase.

**Learning:** Adapt reference patterns critically. Validate that assumptions fit our context before copying.

### Challenge 2: Monorepo Boundary Confusion
**What happened:** Uncertainty about what belongs at monorepo root (Husky, commitlint) vs package level (lint-staged, ESLint config).

**Learning:** Monorepo structure needs clear mental model. Document decisions as they arise.

### Challenge 3: Documentation Lag
**What happened:** File Lists in story records consistently lagged behind actual implementation. Every code review caught documentation issues.

**Learning:** Code quality was high; documentation discipline needs attention. Noted that BMAD File List maintenance feels redundant with Git - will revisit if friction increases.
